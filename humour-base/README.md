## What is a Humour Pattern?

A portable explanation of **why** something is funny. Analyse Humour Gap, Vehicle, Engine, audience reconstruction, pacing, expectation and surprise, empathy, what fails, source evidence, uncertainties and how to create **original** new humour. Names of artists/programmes identify research subjects, not licenses to imitate dialogue, catchphrases, mannerisms or existing routines.

- Thalia's human-facing app already describes checking a Humour Base first. Direct GitHub links in this README are the KISS entry point. Static web pages cannot list directory contents automatically.
- **Publishing boundary:** Commit the owner's reviewed research to this repository only. Contributions from others remain proposals requiring owner review rather than automatic anonymous GitHub writes.

## Using the base with another AI

Read one of the `.md` files, identify its underlying mechanics, and request a **new** joke or scene on an unrelated topic using the abstract pattern. Do not retrieve or reconstruct an existing comic's original routines.
