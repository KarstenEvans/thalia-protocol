# Support Thalia

Thalia is intended to remain an open protocol.

Funding belongs around the project, not inside the canonical protocol.

## Patreon

**https://www.patreon.com/KarstenE**

The repository also contains:

```yaml
# .github/FUNDING.yml
patreon: KarstenE
```

so GitHub can expose the repository-level Sponsor route where supported.

## Separation of concerns

### Canonical protocol

`THALIA_PROTOCOL.md`

No:

- Patreon appeals;
- affiliate tracking;
- retailer promotions;
- daily-joke application behaviour.

### Human-facing app

`thalia-humour-app.md`

Contains the interactive humour experience and one stable supporting-resource reference:

`https://swindon.org.uk/resources/thalia-humour-app.htm`

It does not embed tracked retailer URLs or a direct Patreon appeal.

### Website resource layer

`https://swindon.org.uk/resources/`

May contain:

- original supporting explanation;
- one relevant disclosed affiliate recommendation;
- a normal site/project support route where appropriate.

### Repository support layer

`README.md`, `SUPPORT.md`, the GitHub profile and `.github/FUNDING.yml` may link directly to Patreon.

## Suggested Patreon approach

Keep the initial offer simple. Possible future tiers might be:

- **£3**: project updates / observer tier;
- **£7**: deeper experiments and development notes;
- **£15**: patron tier with occasional Q&A or experiment suggestions.

These are planning ideas only. Do not promise benefits that cannot be delivered consistently.

The point is to fund continuing protocol work, documentation and experiments without putting the open specification behind a paywall.
