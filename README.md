# 🎭 Thalia Protocol

> **Thalia helps minds preserve laughter.**

**Status:** v1.0 Draft / pre-release  
**Type:** Open Human-AI Humour Cognition Protocol

Thalia helps AI systems **understand why humour works and create new humour by transferring the underlying mechanisms**.

It is not a joke database.

> **Jokes are examples. Humour patterns are the knowledge.**

## Two doors into Thalia

### 🤖 Protocol for AIs

Read [`THALIA_PROTOCOL.md`](THALIA_PROTOCOL.md).

This is the canonical protocol: humour gaps, vehicles, engines, reconstruction, pattern families, Humour DNA, Laughter Vectors, AI-native humour, mechanism transfer, feedback and Read The Room.

The canonical protocol contains no daily-joke application behaviour, affiliate mechanics or Patreon appeals.

### 🧑 App for hoomans

Download or upload [`thalia-humour-app.md`](thalia-humour-app.md) into an AI chat.

The app:

- displays a compact HELP menu;
- asks the AI to **create** a fresh joke rather than find one;
- can ask for an optional 1–10 review;
- adapts later humour from feedback;
- requests a fresh AI-created joke at **08:00 local time** where the host genuinely supports scheduled tasks;
- links to both protocols; and
- contains one stable supporting-resource link.

The permanent human-app resource page is:

**https://swindon.org.uk/resources/thalia-humour-app.htm**

Tracked retailer URLs are kept on that website page, not inside the distributed app.

## Website and resource architecture

The project website/resource root is:

- **Website:** https://swindon.org.uk
- **Human-app resources:** https://swindon.org.uk/resources/

Portable human-facing Markdown apps use one stable Swindon resource URL. The actual retailer tracking link lives on that matching HTML page, so an affiliate programme or recommended product can be changed centrally without redistributing the Markdown app.

For this app:

```text

        ↓
https://swindon.org.uk/resources/thalia-humour-app.htm
        ↓

```

## Contributing

Useful contributions include:

- clearer definitions of humour mechanisms;
- cross-cultural examples and counterexamples;
- tests showing whether an AI can explain *why* something is funny;
- tests showing whether an AI can transfer a mechanism into a genuinely new joke;
- audience-feedback experiments;
- machine-readable Humour DNA / Laughter Vector formats;
- Read The Room tests;
- AI-to-AI interoperability and conformance tests.

The aim is not to pickle punchlines in formaldehyde. It is to understand the machinery that makes them move.
